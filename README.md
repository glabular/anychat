# anychat

Desktop chat client for [Anytype](https://anytype.io/).

## Requirements (Windows)

1. [.NET 10 Desktop Runtime (Windows x64)](https://dotnet.microsoft.com/download/dotnet/10.0)
2. [.NET 10 ASP.NET Core Runtime (Windows x64)](https://dotnet.microsoft.com/download/dotnet/10.0)
3. [WebView2](https://developer.microsoft.com/microsoft-edge/webview2/) (usually already installed on Windows 10/11).

## Download

1. Open [Releases](https://github.com/glabular/anychat/releases).
2. Download `anychat-VERSION-win-x64.zip`
3. Unzip and run `AnyChat.NET.Desktop.exe`
